# Bundled FFmpeg

This folder holds the FFmpeg binaries that ship with noEncodeEdit. They are not
stored in git; run `npm run fetch-ffmpeg` from the project root to download them.

- Build: [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) `n9.0.2-25-g67b60c310b`, win64, GPL, shared
- License: GPL v3 (copied here as `FFMPEG-LICENSE.txt`)
- Source: FFmpeg commit [`67b60c310b`](https://github.com/FFmpeg/FFmpeg/commit/67b60c310b) and the BtbN build scripts
